# OzzysTower progress

Completed: project-scoped configuration, six specialist roles, routing and ownership rules, reusable operating instructions, low-usage policy, verification procedures, DeepSeek review handoff, and usage/audit ledger.

Resolved: fixed-role escalation precedence and conditional Git/worktree guidance. Low-usage defaults use Luna/low for lead and simple tasks, one specialist at a time by default, and risk-based additional review. Paid DeepSeek use and data transfer require explicit approval for each attempt.

Verification guidance and current limits are in `VERIFICATION.md`, `DEEPSEEK.md`, and `LOW-USAGE.md`. Per-machine run records are stored under the Git-ignored `.ozzystower/` directory and are not part of the public repository.

Reuse guidance: read the target project's own instructions and summary first. Apply OzzysTower configuration selectively and keep project-specific source, decisions, backups, and history in that project's repository.
